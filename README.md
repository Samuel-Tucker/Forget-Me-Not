# Forget Me Not

Keep the details you type all the time, and copy any of them in one click.

A side-panel notebook for the things you keep retyping: addresses, VAT numbers, account references and similar snippets. Add a detail with a name, type, value and tags, then type any part of those in the search box. Matching is fuzzy, and clicking a result (or pressing Enter) copies its value to the clipboard, ready to paste into the website.

Download, install steps and screenshots: https://sams.help/extensions/forget-me-not

## Features

- Side panel opens from the toolbar icon
- Fuzzy search across name, type, tags and value
- Click a result, or press Enter, to copy its value
- Add, edit and delete saved details from the gear (manage) view
- Details are stored locally in the browser and never synced

## Permissions

- `storage`: To keep your saved details in this browser profile's local extension storage.
- `sidePanel`: To show Forget Me Not in the browser's side panel.
- `clipboardWrite`: To copy a detail's value to your clipboard when you click it.

## Privacy

No network access. Nothing leaves your browser: saved details stay in this profile's local extension storage and are not synced to a server. They are stored as plain text, so keep passwords and card numbers out of it.

## Install (Chrome or Helium)

1. Download this repo (Code → Download ZIP) and unzip it, or grab the zip from the link above.
2. Open `chrome://extensions` (Helium: `helium://extensions`) and turn on Developer mode.
3. Click **Load unpacked** and choose the folder that contains `manifest.json`.
